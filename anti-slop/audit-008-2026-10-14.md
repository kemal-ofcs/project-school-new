# Audit 008: Nilai Akhir Fase N2a

Tanggal: 2026-10-14
Cakupan: UI baru Fase N2a: `components/nilai/PengaturanNilai.tsx` (jenis penilaian dan bobot, bobot kehadiran, Hari Sekolah per unit), `components/nilai/RekapNilai.tsx` (rekap nilai akhir dan ekspor Excel), serta tab baru di kedua halaman `/nilai` (Web/Desktop dan Mobile). Diperiksa dari kode; belum dijalankan di browser atau perangkat.
Mode: antislop setelah selesai (pilihan User untuk sesi ini). User meminta temuan langsung diperbaiki setelah `bun run check`.

Prioritas mengikuti tingkat aturan: Hard Gate = TINGGI, Purpose-Gate = SEDANG, Quality Lock = RENDAH.

## SEDANG

### 1. Tab `/nilai` tidak terhubung ke panelnya (R-32, C-4)
- **Bukti:** tombol tab memakai `role="tab"` dan `aria-selected`, tetapi tidak punya `id`/`aria-controls`, dan isi tab tidak dibungkus `role="tabpanel"`. Pembaca layar mengumumkan "tab, terpilih" tanpa bisa menunjukkan bagian halaman mana yang dikendalikannya. `TagihanWorkspace` sudah memakai pola yang lengkap.
- **Perbaikan:** setiap tab mendapat `id` dan `aria-controls="panel-nilai"`, isinya dibungkus `role="tabpanel"` berlabel tab yang aktif.

## RENDAH

### 2. Peringatan ekspor tidak bisa diurungkan (C-4)
- **Bukti:** saat ada nilai kosong, tombol ekspor berganti menjadi "Ya, ekspor tetap" tanpa pilihan untuk membatalkan; peringatannya baru hilang setelah rekap dihitung ulang.
- **Perbaikan:** tombol "Jangan ekspor" di samping peringatannya.

### 3. Konfirmasi hapus jenis tanpa jalan mundur (C-4)
- **Bukti:** setelah "Hapus jenis", tombolnya berganti "Ya, hapus jenis ini" tanpa pilihan batal di dialog itu; satu-satunya jalan keluar adalah menutup dialog.
- **Perbaikan:** tombol "Jangan hapus" di samping konfirmasinya.

### 4. Bobot jenis nonaktif terkunci tanpa alasan (C-4)
- **Bukti:** isian bobot jenis nonaktif dinonaktifkan, dan barisnya hanya bertuliskan "Nonaktif". Pengguna tidak tahu kenapa angkanya tidak bisa diubah. Pola yang sama dengan temuan 3 audit 006.
- **Perbaikan:** keterangannya menjadi "Nonaktif, aktifkan dulu untuk memberi bobot".

## Lolos

- **R-02:** tidak ada tanda pisah panjang pada teks baru.
- **R-17/R-38:** semua angka (rata-rata, bobot efektif, persen kehadiran, nilai akhir) datang dari backend; layar hanya menjumlahkan bobot yang sedang diketik untuk menunjukkan totalnya, dan validasinya tetap di backend.
- **R-26/R-32:** semua kontrol berlabel, termasuk isian bobot (`sr-only` menyebut nama jenisnya) dan tombol "Ubah jenis <nama>"; dialog memakai `Modal` bersama; setiap aksi mutasi dijaga `isSubmittingRef`.
- **R-27:** pengaturan dan rekap punya keadaan memuat, galat dengan "Coba muat lagi"/"Hitung ulang", dan kosong yang memberi arah ("Pilih tahun ajaran, rombel, dan mata pelajaran").
- **R-03:** isian dan tombol `min-h-11`; tabel rekap bergulir di wadahnya sendiri, tidak membuat halaman melebar; pilihan hari membungkus ke baris berikut di ponsel.
- **R-34:** warna aksen baru (`text-amber-100`, `text-emerald-300`, `border-amber-500/60`) sudah diinversi di `globals.css` Web dan variabel tema Mobile.
- **Kejujuran data:** rekap dan ekspor menyebut waktu hitung dan bahwa nilainya belum dibekukan; ekspor memperingatkan jumlah nilai kosong yang dihitung 0 sebelum berkas dibuat.

## Tindak lanjut (2026-10-14)

User meminta semua temuan langsung diperbaiki setelah `bun run check`. Semuanya sudah dikerjakan.

1. **Selesai.** Tab `/nilai` di Web/Desktop dan Mobile terhubung ke `role="tabpanel"` lewat `id`/`aria-controls`/`aria-labelledby`.
2. **Selesai.** Peringatan ekspor punya tombol "Jangan ekspor".
3. **Selesai.** Konfirmasi hapus jenis punya tombol "Jangan hapus".
4. **Selesai.** Jenis nonaktif menjelaskan bahwa ia perlu diaktifkan dulu untuk diberi bobot.
